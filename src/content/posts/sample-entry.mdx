This page doubles as a reference for writing an entry. Each feature shown below is written in plain Markdown, so you can open `src/content/posts/sample-entry.mdx` to see the source next to the result.

## The header

Every entry starts with a short block between two `---` lines:

```yaml title="src/content/posts/my-entry.mdx"
---
title: "Writing a tiny HTTP server in C"
date: 2026-12-01
summary: "One sentence shown on the index and in link previews."
tags: [c, networking]
series: "HTTP server"   # optional
draft: true             # optional; hidden on the live site
---
```

The file name becomes the address, so `my-entry.mdx` is published at `/journal/my-entry`. The issue number is assigned automatically by date.

## Footnotes

Write a footnote with `[^1]` in the text and the note itself anywhere below.[^1] On a wide screen the note appears in the margin beside the line; on a phone it appears at the end of the entry.[^2]

## Code

Fenced code blocks are highlighted when the site is built. A title and highlighted lines are optional:

```c title="echo.c" {4-5}
#include <stdio.h>

int main(void) {
    char buf[256];
    while (fgets(buf, sizeof buf, stdin))
        fputs(buf, stdout);
    return 0;
}
```

Inline code such as `fgets` gets a quieter treatment.

## Asides

Wrap a passage in `<Note title="...">` and `</Note>` to set it apart, as the box at the top of this page does.
